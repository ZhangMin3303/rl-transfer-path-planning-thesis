# Publication Notes

This repository is prepared as a public portfolio version of the undergraduate thesis project.

## Included

- MATLAB source code for the path-planning experiments.
- Selected result figures showing mazes, learned paths, reward curves, step curves, and AUC-style comparisons.
- Concise technical documentation for GitHub and interview preparation.
- A MATLAB runner for reproducing the execution check.

## Excluded

- Original thesis `.docx` and `.pdf`.
- Defense slides `.pptx`.
- Student ID, school authorization pages, signatures, acknowledgements, and private personal information.
- MATLAB `.mat` cache/model files.
- System files such as `desktop.ini`.

## Public-positioning Advice

Use this as a thesis and research-practice project. The strongest phrasing is:

> Transfer reinforcement learning for interpretable grid-maze path planning.

Avoid overstating it as a deployed robot navigation system or a deep reinforcement learning project. It is strongest when presented as a complete undergraduate research project with clear baseline, transfer design, comparative experiments, and reproducibility checks.
